# IFRS Print Studio - מערכת סדר והפקת דפוס לתקינה חשבונאית

מערכת עריכה, סדר דפוס והפקת מסמכי PDF ותקינה חשבונאית בינלאומית (IFRS) בעברית, בהתאם לכללי הטיפוגרפיה, העימוד והסגנון של **המוסד הישראלי לתקינה בחשבונאות**.

---

## תכונות מרכזיות (Key Features)

- **תצוגת A4 מדויקת וחלוקה לעמודים:** חלוקה חכמה לדפי A4 נפרדים (`210mm × 297mm`) לפי שטח הדפסה אמיתי (~245mm נטו לכל עמוד).
- **סעיפים תלויים רשמיים (Hanging Paragraphs):** תמיכה מלאה בהזחה תלויה ברוחב 44pt עבור סעיפי תקן (`IG1`, `IE1`, `BC1` ועוד) לצד טקסט מיושר לשני הצדדים (Justified).
- **טבלאות חשבונאיות תקניות:**
  - שורות יחידת מטבע (`י"מ`) עם קו תחתון של 0.75pt.
  - שורות סיכום חשבונאיות עם קו עליון יחיד וקו תחתון כפול (Double underline).
  - שמירה על כיווניות מספרים שליליים בסוגריים `(2,620)` וקווים מפרידים `–` ב-RTL (Tabular numerals).
  - טבלאות תרשים החלטה ובדיקות עם רשת 0.5pt וכותרת אפורה.
- **בקרת עדכון תצוגה (Manual / Controlled Preview Update):** אפשרות להקליד בחופשיות ללא ריצוד של התצוגה המקדימה בכל מקש, ועדכון בלחיצה על כפתור "עדכן תצוגה מקדימה" או בקיצור `Ctrl+Enter`.
- **היסטוריית שינויים (Undo / Redo):** כפתורי "אחורה" ו"קדימה" ותמיכה מלאה ב-`Ctrl+Z` ו-`Ctrl+Y` לתיקון מהיר של טעויות.
- **ניקוי פלט AI בלחיצה אחת:** הסרת משפטי פתיחה של מודלים ("להלן התרגום..."), מחיקת הערות מתרגם, והמרת כתב נטוי שבור (`*`) להדגשה תקנית (`**`).
- **הדפסה מבודדת ל-PDF:** פתיחת חלון הדפסה נקי עם גופני David Libre ו-Assistant ללא עיוותי מסגרת (iframe).
- **שמירת HTML עצמאי:** הורדת קובץ HTML עצמאי מוכן להדפסה עם אפשרות לבחירת שם הקובץ.

## התקנה והרצה מקומית (Getting Started)

```bash
# התקנת תלויות
npm install

# הפעלת שרת פיתוח מקומי (פורט 3000)
npm run dev

# בניית גרסת ייצור (Production Build)
npm run build
```
